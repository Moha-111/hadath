# السيناريو الاصطناعي

**حادث افتراضي متعدد الإصابات:** انهيار جزئي لمدرّج مؤقت أثناء فعالية مجتمعية في «مجمّع الواحة للفعاليات» الخيالي. ليس إعادة تمثيل لأي حدث حقيقي أو هجوم، ولا يستخدم بيانات ضحايا أو مخططات منشآت فعلية. «14 مصابًا» تقدير اصطناعي لا تُبنى عليه قرارات علاجية.

التعريف في [`src/domain/scenario.ts`](../src/domain/scenario.ts): 40 خطوة، لكل خطوة دور فاعل وأمر وعنوان. يمكن تشغيله:

- من الواجهة: «مشغّل السيناريو» أسفل الشاشة (خطوة بخطوة، حتى النهاية، إعادة).
- يدويًا: بأزرار كل واجهة (القوالب المقترحة مأخوذة من السيناريو نفسه فيبقى المشغّل متزامنًا).
- دون واجهة: `npm run scenario`.
- برمجيًا من وحدة التحكم: `hadath.runTo('s20')`.
